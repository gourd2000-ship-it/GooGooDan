# Roadmap: 구구단 챌린지

작성일: 2026-08-28

## 구현 순서

1. **챌린지 핵심 흐름** — 완료
   - 홈의 두 기존 연습 카드와 오른쪽 절반 챌린지 카드
   - 답 말하기·답 누르기·식 말하기·식 누르기 선택 후 방식 고정
   - 20·25·30문제 설정, 1~9단 혼합 출제, 별 등급

2. **입력·결과·복습** — 완료
   - 누르기 챌린지 진행과 문항별 채점
   - 말하기 챌린지 녹음 화면 및 혼합 문항 서버 검증
   - 결과, 오답만 같은 방식으로 재도전

3. **랭킹 데이터 기반** — 코드·마이그레이션 준비 완료
   - 문제 수와 방식별 독립 랭킹 선택 규칙
   - `server/migrations/003_challenge_records.sql`
   - 운영 DB 마이그레이션 적용 및 API/화면 연결 필요

## 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 긴 말하기 챌린지가 60초를 넘김 | 음성 품질·비용을 확인한 뒤 클라이언트와 서버 제한을 함께 상향 |
| 서로 다른 난이도의 기록 비교 | 문제 수와 네 챌린지 방식을 분리한 랭킹 유지 |
| 마이그레이션 미적용 | 운영 DB 적용 전에는 챌린지 랭킹 저장을 활성화하지 않음 |
