# GooGooDan PRD: 말하는·누르는 구구단

## 0. 승인 대상과 범위

이 문서는 기존 **말하는 구구단**에 객관식 방식의 **누르는 구구단**을 추가하는 제품 요구사항이다. 이번 변경은 아래 세 기능 묶음으로 나누어 구현·검증한다.

| 기능 묶음 | 책임 | 주요 모듈 |
| --- | --- | --- |
| 학습 방식과 문항 규칙 | 방식 선택, 단·순서 설정, 중복 없는 10문제 생성 | 홈 화면, 순수 문항 생성 로직, 상태 저장소 |
| 누르는 구구단 공통 진행 | 4지선다, 즉시 피드백, 다음 문제·결과 전환 | 누르는 연습 화면, 결과 모델, 선택지 엔진 |
| 누르는 구구단 게임 모드 | 답·식·혼합 출제 규칙 | 답 고르기, 식 고르기, 혼합 모드 |
| 기록과 명예의 전당 | 방식별 기록 저장 및 조회·표시 | API, DB 마이그레이션, 랭킹 화면 |

이 PRD와 `docs/roadmap.md`, `tasks/plan.md`의 계획을 승인하기 전에는 기능 코드, 의존성, 데이터베이스를 변경하지 않는다.

## 1. 목표

아이들이 한 단의 구구단을 말로 답하거나 보기에서 눌러 답할 수 있게 하고, 각 학습 방식의 성과를 서로 섞지 않고 명예의 전당에서 확인하게 한다.

## 2. 사용자 흐름

`이름 입력 → 홈에서 학습 방식 및 설정 선택 → 연습 10문제 → 결과 → 방식별 명예의 전당`

기존 말하는 구구단의 녹음·AI 채점 흐름은 유지한다. 누르는 구구단은 AI 채점이나 마이크 권한을 사용하지 않는다.

## 3. 기능 요구사항

### 3.1 홈: 학습 방식과 설정

- 홈 화면에는 **말하는 구구단**과 **누르는 구구단** 카드가 함께 보인다.
- 두 카드 모두 다음 설정 영역을 표시한다.
  - `몇 단을 연습할까요?`: 2단부터 9단까지
  - `어떻게 연습할까요?`: 순서대로, 거꾸로, 섞어서
- 한 번에 하나의 학습 방식만 선택할 수 있다.
  - 누르는 구구단을 선택하면 말하는 구구단 카드와 그 안의 설정 버튼은 비활성 상태로 표시한다.
  - 말하는 구구단을 선택하면 누르는 구구단 카드와 그 안의 설정 버튼은 비활성 상태로 표시한다.
- 선택된 카드의 설정만 변경할 수 있고, 시작 버튼은 선택된 방식의 설정으로 연습을 시작한다.
- 누르는 구구단 카드가 선택된 경우에만 `어떤 문제를 풀까요?` 설정을 추가로 활성화한다.
  - `답 고르기`
  - `식 고르기`
  - `답과 식 섞기`
- 기본 선택값은 현재 서비스와 동일하게 말하는 구구단, 2단, 순서대로로 둔다.

### 3.2 공통 문항 순서

- 한 번의 연습은 선택한 단의 곱셈 문제 10개(곱하는 수 1부터 10까지)로 구성한다.
- 같은 연습 안에 같은 문제가 두 번 나타나면 안 된다.
- `순서대로`는 `×1`부터 `×10`까지, `거꾸로`는 `×10`부터 `×1`까지 표시한다.
- `섞어서`는 1부터 10까지를 한 번씩 포함한 무작위 순열이다. 편향된 정렬 비교 함수가 아닌 Fisher–Yates 셔플을 사용한다.
- 이 규칙은 말하는 구구단과 누르는 구구단에 동일하게 적용한다.

### 3.3 누르는 구구단 공통 규칙

- 시작 전 `답 고르기`, `식 고르기`, `답과 식 섞기` 중 정확히 하나를 선택한다. 기본값은 `답 고르기`다.
- 매 문제 아래에는 4개의 선택지를 버튼으로 보여준다. 보기의 표시 순서는 매 문제 섞는다.
- 선택지는 정답 1개와 서로 다른 오답 3개로 이루어진다. 정답은 반드시 보기 중 하나여야 한다.
- 사용자가 보기를 누르면 즉시 정답 또는 오답 피드백을 명확히 표시하고, 같은 문제에서 다른 보기를 다시 고를 수 없게 한다.
- 피드백을 약 800ms 보여 준 뒤 자동으로 다음 문제로 넘어간다. 마지막 문제라면 결과 화면으로 이동한다.
- 결과에는 총 정답 수, 총점, 걸린 시간을 표시한다. 누르는 구구단의 기본 점수 규칙은 기존 방식 난이도 가중치(순서대로 10점, 거꾸로 12점, 섞어서 15점)를 정답 수에 곱해 계산한다.
- 누르는 구구단에서는 녹음 버튼, 마이크 안내, AI 채점 요청을 표시하거나 호출하지 않는다.

### 3.4 누르는 구구단 게임 모드

| 게임 모드 | 문제 영역 | 정답 보기 | 오답 보기 |
| --- | --- | --- | --- |
| 답 고르기 | `3 × 4 = ?` | `12`처럼 계산 결과 | 선택한 단에서 계산한 서로 다른 결과 3개 |
| 식 고르기 | `12 = ?` | `3 × 4`처럼 해당 답을 만드는 식 | 선택한 단의 다른 곱셈식 3개 |
| 답과 식 섞기 | 위 두 형식을 모두 사용 | 문제 형식에 맞는 정답 | 문제 형식에 맞는 오답 3개 |

- **답 고르기:** 식을 문제로 표시하고 숫자 답을 고른다. 네 숫자 보기는 모두 달라야 한다.
- **식 고르기:** 숫자 답을 문제로 표시하고 곱셈식을 고른다. 네 식은 모두 달라야 하며 정답 외의 식은 해당 숫자를 만들면 안 된다.
- **답과 식 섞기:** 3.2절에서 만든 10개 문항 순서는 그대로 유지하고, 그 10개 위치 중 5개를 답 고르기·나머지 5개를 식 고르기로 배정한다. 따라서 순서대로·거꾸로·섞어서의 문제 등장 순서를 훼손하지 않으며, 한 번의 연습에는 두 종류가 반드시 모두 등장한다.
- 어떤 게임 모드에서도 하나의 연습 안에서 같은 곱셈식(예: `3 × 4`)은 두 번 출제되지 않는다. 식 고르기와 혼합 모드의 보기는 출제된 문제 수 중복 여부와 별개로, 오답 선택지로만 재사용될 수 있다.

### 3.6 방식별 명예의 전당

- 명예의 전당에 최상위 학습 방식 탭을 둔다.
  - `말하는 구구단`
  - `누르는 구구단`
- 각 방식 안에서는 기존처럼 전체 및 2단~9단 필터를 제공한다.
- 랭킹 조회와 표시는 선택한 학습 방식의 기록만 대상으로 한다. 두 방식의 기록을 합산하거나 같은 목록에 섞지 않는다.
- 랭킹 항목은 이름, 단, 점수, 소요 시간, 기록 시점을 계속 표시한다.

## 4. 데이터와 API 계약

### 4.1 기록 데이터

기존 `records` 테이블에 `practice_type`과 `tap_game_mode`를 추가한다.

- `practice_type` 허용 값: `speech`, `tap`
- `tap_game_mode` 허용 값: `answer`, `expression`, `mixed`; 말하기 기록에서는 `NULL`이다.
- 기존 기록: `speech`로 안전하게 이관하고, `tap_game_mode`는 `NULL`로 둔다.
- `practice_type`은 기본값 `speech`, `NOT NULL`, 허용 값 제약 조건을 둔다. `tap_game_mode`는 누르는 기록일 때만 세 값 중 하나가 되도록 제약 조건을 둔다.
- 랭킹 조회 성능을 위해 `practice_type`, `table_number`, `score`, `total_time_ms` 사용 패턴에 맞는 인덱스를 검토한다.

### 4.2 서버 엔드포인트

- `GET /api/ranking`은 `practiceType=speech|tap` 필터를 받는다. 누락 또는 허용하지 않는 값은 안전한 기본값 또는 400 응답으로 일관되게 처리한다.
- 기존 `POST /api/evaluate`가 저장하는 모든 말하기 기록에는 `practice_type: speech`를 명시한다.
- 누르는 구구단 완료 기록은 별도 `POST /api/record` 엔드포인트로 저장한다.
  - 서버는 이름, 단, 순서, 게임 모드, 정답 수, 소요 시간을 형식·범위 검증하고 점수를 서버에서 계산한다.
  - 성공 시 `practice_type: tap` 및 선택한 `tap_game_mode`를 저장하고 결과에 필요한 값을 돌려준다.
  - 비정상 입력·DB 오류에는 사용자에게 안전한 오류 메시지를 반환한다.

## 5. 품질 및 접근성 요구사항

- 답안 버튼은 마우스·터치·키보드로 조작 가능하고, 피드백 상태가 보조기술에 전달되어야 한다.
- 비활성 카드와 버튼은 시각적으로 구분하고 실제 입력도 막아야 한다.
- 한 문제를 답하는 중 중복 클릭·중복 저장이 발생하지 않아야 한다.
- 네트워크 실패로 누르는 기록 저장에 실패해도 결과와 정답 수는 사용자에게 보이며, 재시도 가능한 안내를 제공한다.
- 기존 말하기 연습, 로그인, 랭킹 및 배포 빌드가 회귀하지 않아야 한다.

## 6. 수용 기준

1. 홈에서 두 학습 방식 중 하나만 활성화할 수 있고, 활성 방식의 단·순서 설정으로 시작된다.
2. 세 순서 모두 10개의 고유한 문제를 정확한 규칙으로 생성한다.
3. 누르는 구구단 시작 전 답 고르기·식 고르기·답과 식 섞기 중 하나를 선택할 수 있고, 선택하지 않은 모드로는 시작되지 않는다.
4. 답 고르기는 숫자 답 보기 4개, 식 고르기는 식 보기 4개를 표시하며, 각각 정답 하나와 중복 없는 오답 세 개를 가진다.
5. 답과 식 섞기는 답 고르기 5문제와 식 고르기 5문제를 모두 포함하며, 같은 곱셈식이 출제 문제로 반복되지 않는다.
6. 답을 한 번 누르면 피드백 후 다음 문제로 이동하고, 10번째 답 뒤 결과 화면에 정답 수·점수·시간이 표시되며 누르는 기록에 게임 모드가 저장된다.
7. 말하기 연습은 기존 AI 채점 흐름으로 계속 동작하며, 저장된 기록의 방식은 `speech`다.
8. 명예의 전당의 두 방식 탭은 서로의 기록을 노출하지 않는다.
9. 계획된 단위·컴포넌트·서버 테스트와 린트·프로덕션 빌드가 모두 통과한다.

## 7. 명시적 제외 범위

- 여러 단을 한 번에 선택하는 연습
- 사용자 계정별 개인 기록과 인증 체계 개편
- 답안을 음성·객관식 혼합으로 출제하는 모드
- 오프라인 기록 동기화 또는 랭킹 재정렬 정책 변경
